**ผู้พัฒนา:** `ARISSARA.K` — กลุ่มงานเภสัชกรรม โรงพยาบาลเจริญกรุงประชารักษ์

ส่วนขยายรวม 2 ระบบไว้ในแผงลอยเดียวกัน (ใช้ได้ทั้ง **Opera / Chrome** และ **Internet Explorer / Edge IE Mode**) เชื่อมฐานข้อมูล Google Sheets ชุดเดียวกัน (`Auto Crat-EGPxx`, `MISSxx`, และ `EGP+MIS ทะเบียนบริษัท`):

1. **แท็บ `📦 จัดซื้อ/ตรวจรับ (8 ขั้น)`:** กรอกระบบจัดซื้อ/เช่า กทม. (`http://bmamisapp11.bma.go.th:7778/PurHire/...`) อัตโนมัติครบ 8 ขั้นตอน + ตั้งชื่อ PDF ใบตรวจรับ 2 ไฟล์ในข้อ 13 อัตโนมัติ
2. **แท็บ `💰 เบิกจ่าย MIS2 (ฎีกา)`:** ช่วยกรอกหน้า **Oracle Forms (`FRM_PAY_DOC : บันทึกใบขอเบิก`)** ครบทั้ง 3 ขั้น (ใบตรวจรับ + VAT 7% / หัก 1% ยกเว้น 4 บริษัท + แท็บผู้รับเงิน 5 ช่อง + แท็บรายละเอียดเบิก + บันทึกเลขฎีกากลับลง `MISSxx` คอลัมน์ H)

## 🚀 วิธีติดตั้ง (ทำครั้งแรกครั้งเดียว)

### 1. ติดตั้งบน Opera / Chrome
1. เปิด Opera แล้วพิมพ์ **`opera://extensions`** (หรือ `chrome://extensions`)
2. เปิดสวิตช์ **`Developer mode`** มุมขวาบน
3. กด **`Load unpacked`** แล้วเลือกโฟลเดอร์ **`bma-mis-autofill-extension`**
4. *(ถ้าเคยติดตั้งเวอร์ชันเก่าไว้แล้ว)* ให้ดับเบิลคลิก **`UPDATE_FROM_GITHUB.bat`** แล้วกดปุ่ม **Reload** บนการ์ดส่วนขยาย

### 2. ติดตั้งบน Internet Explorer (IE) / Edge IE Mode
1. ดับเบิลคลิกไฟล์ **`RUN_IE_AUTOFILL.bat`**
2. ระบบจะสร้างปุ่มลัด **`BMA_MIS_AutoFill`** บนแถบ Favorites ของ IE ให้ (และเปิดตัวช่วย Oracle Forms ให้อัตโนมัติ)
3. เวลาเปิดหน้าจัดซื้อ (`PurHire`) หรือหน้า MIS2 (`bmasso.bma.go.th`) ใน IE ให้คลิกปุ่ม **`BMA_MIS_AutoFill`** บนแถบ Favorites 1 ครั้ง แผงควบคุมจะเด้งขึ้นทันที

### 3. ติดตั้งตัวช่วย Oracle Forms (เพื่อให้แท็บ "เบิกจ่าย MIS2" ยิงเข้าหน้าต่าง Oracle Forms อัตโนมัติ)
- ดับเบิลคลิก **`INSTALL_AUTOSTART_BRIDGE.bat`** เพียงครั้งเดียว:
  - ตั้งค่าให้ตัวช่วยเปิดทำงานเงียบๆ ใน System Tray (มุมขวาล่างใกล้เวลา) ทุกครั้งที่เปิดเครื่อง *(ไม่ต้องใช้สิทธิ์ Administrator)*
  - สร้างไอคอนลัดบนหน้า Desktop ไว้ให้ด้วย
- *(หมายเหตุ: หากใช้เครื่องที่ยังไม่ได้เปิดตัวช่วย แท็บเบิกจ่ายในส่วนขยายก็ยังใช้งานคำนวณภาษี ตรวจเบิกซ้ำ และกดปุ่ม **`📋`** คัดลอกไป **`Ctrl+V`** เองได้ทันที)*

## 📋 วิธีใช้งานประจำวัน

### การสลับแท็บและการเลือกรายการร่วมกัน
- ด้านบนของแผงควบคุมมีปุ่มสลับ 2 ระบบ: **`📦 จัดซื้อ/ตรวจรับ (8 ขั้น)`** | **`💰 เบิกจ่าย MIS2 (ฎีกา)`**
  - เมื่อเปิดหน้า `bmasso.bma.go.th` ระบบจะสลับไปที่แท็บ **`💰 เบิกจ่าย MIS2`** ให้อัตโนมัติ
- **เลือกปีงบประมาณ** (เริ่มที่ปี `70` — กด `➕ เพิ่มปีงบ / ตั้งค่าไฟล์` เพื่อเพิ่มปีถัดไปและสลับไฟล์ Google Sheets ได้)
- **ค้นหารหัส `ซ.`** (เช่น `1งบ`, `7งบ`) แค่ครั้งเดียว ข้อมูลจะพร้อมใช้งานทั้ง 2 แท็บทันที

### โหมด 1: จัดซื้อ / ตรวจรับ (8 ขั้นตอน)
1. **ขั้น 1 เห็นชอบ ➔ ขั้น 2 เสนอราคา ➔ ขั้น 3 อนุมัติ ➔ ขั้น 4 สัญญา ➔ ขั้น 5 ส่งมอบ** *(พิมพ์เลขที่บิลในช่องเลขที่บิลก่อน)* **➔ ขั้น 6 รายงานผลตรวจรับ**
   - ระบบกรอกให้อัตโนมัติทันทีที่เปิดหน้าและรอกด **`✅ อนุมัติบันทึก`** ก่อนบันทึกทุกครั้ง
   - หากมีประวัติครบทั้งรหัสจัดซื้อ/ใบสั่งซื้อ/ใบตรวจรับใน `MISSxx` แล้ว จะขึ้นเตือนสีแดงและล็อกขั้น 1–6 ป้องกันลงซ้ำ
2. **ขั้น 7 คณะกรรมการตรวจรับ (ข้อ 12):** เลือกชุดกรรมการ (`ชุดที่ 1` / `ชุดที่ 2`) ระบบแยกวงเงิน `>= 100,000` (4 แถว) และ `< 100,000` (2 แถว) พร้อมล้าง `undefined` ให้เอง
3. **ขั้น 8 พิมพ์ใบตรวจรับพัสดุ (ข้อ 13):** กด **`✅ อนุมัติแสดงรายงาน`** เพื่อตั้งชื่อและบันทึกไฟล์ PDF ทั้ง 2 ไฟล์ตามเลขที่ใบตรวจรับและรหัสรายการอัตโนมัติ

### โหมด 2: เบิกจ่าย MIS2 (`FRM_PAY_DOC`)
1. **ตั้งพิกัด 1 ครั้งต่อเครื่อง:** เปิดหน้า `FRM_PAY_DOC` ใน IE ➔ กดปุ่ม **`🎯 ตั้งพิกัด`** บนแผงลอย ➔ เอาเมาส์ชี้กลางแต่ละช่องแล้วกด **`F8`** (กด **`F9`** เพื่อข้าม) *(ถ้าเคยตั้งพิกัดไว้ใน `bma-mis2-pay-autofill` แล้ว ระบบจะดึงพิกัดเดิมมาใช้ให้อัตโนมัติ!)*
2. **ขั้นที่ 1 (`1. ใบตรวจรับ`):** กด **`⚡ ขั้น 1`** (กรอกเลขใบตรวจรับ + กดแว่นขยาย 🔍) ➔ **`⚡ ขั้น 1.5`** (Popup เลือกงบ) ➔ **`⚡ ขั้น 1.6`** (กรอก VAT 7% + หักภาษี 1% โดยยกเว้น 1% เป็น `0.00` อัตโนมัติให้ สภากาชาด, เอเบิ้ล, องค์การเภสัชกรรม, ยูนีซัน)
3. **ขั้นที่ 2 (`2. ผู้รับเงิน`):** ตรวจ 5 ช่อง (`จ่ายให้`, `โดยมอบให้` *(งบเอดส์ตั้งตรงกับจ่ายให้อัตโนมัติ)*, `รหัสธนาคาร`, `รหัสสาขา 4 หลัก`, `เลขที่บัญชี`) ➔ กด **`⚡ ขั้น 2`**
4. **ขั้นที่ 3 (`3. รายละเอียด`):** ตรวจชื่อผู้ขอเบิก (`นางอรชุมา หุตะโกวิท` แก้ไขได้), วันที่เบิก, คำอธิบาย `(ค่า...)` ➔ กด **`⚡ ขั้น 3`**
5. **หยุดก่อนบันทึกทุกครั้ง:** โปรแกรมไม่มีคำสั่ง Save / F10 ให้เจ้าหน้าที่ตรวจสอบและกดบันทึกเอง (กด **`ESC`** หยุดฉุกเฉินได้ตลอดเวลา)
6. **บันทึกเลขที่ใบขอเบิกกลับลง `MISSxx`:** นำเลขที่ใบขอเบิกที่ได้พิมพ์ลงช่องด้านล่างแล้วกด **`💾 บันทึกลง MISSxx`** เพื่อเก็บลงคอลัมน์ H ป้องกันเบิกซ้ำ

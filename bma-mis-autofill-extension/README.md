# BMA MIS Auto-Filler (ส่วนขยาย Opera / Chrome สำหรับกรอกระบบจัดซื้อ/เช่า กทม. อัตโนมัติ ครบ 8 ขั้นตอน)

ส่วนขยายนี้เชื่อมต่อกับฐานข้อมูล Google Sheets (**`Auto Crat-EGP70`** และ **`MISS70`**) ของกลุ่มงานเภสัชกรรม โรงพยาบาลเจริญกรุงประชารักษ์ เพื่อกรอกข้อมูลลงในเว็บ `http://bmamisapp11.bma.go.th:7778/PurHire/...` อัตโนมัติครบทั้ง **8 ขั้นตอน** (รวมหน้าต่าง Popup ย่อยทั้งหมด)

### กฎการดึงข้อมูลจาก Google Sheets และระบบป้องกันการลงซ้ำ
1. **การกรองรายการ (`Auto Crat-EGP70` แท็บ `main` คอลัมน์ B `ซ.`):**
   - กรองเฉพาะรายการที่ลงท้ายด้วย **`...งบ`** (เงินงบประมาณ กทม.) และ **`...งบเอดส์`** (`...เอดส์` / `...AIDs`) เท่านั้น
2. **ยอดเงินของโครงการ:**
   - ดึงจากชีต **`MISS70` คอลัมน์ E (`จำนวนเงิน`)** เป็นหลัก
3. **ระบบป้องกันการลงข้อมูลซ้ำ (`MISS70` คอลัมน์ B, C, D):**
   - ถ้ารายการใดมี **รหัสจัดซื้อ**, **เลขที่ใบสั่งซื้อ**, และ **เลขที่ใบตรวจรับ** ใน `MISS70` ครบทั้ง 3 ช่องแล้ว ระบบจะขึ้นข้อความแจ้งเตือนสีแดง **`"มีประวัติการลงข้อมูลแล้ว"`** และล็อกปุ่มห้ามลงข้อมูลซ้ำเด็ดขาด
4. **เกณฑ์คณะกรรมการตรวจรับ (แยกตามยอดเงินจาก `MISS70` คอลัมน์ E):**
   - **`>= 100,000` บาท**: กรอก 4 แถว (ประธานกรรมการ + กรรมการ + กรรมการ + เจ้าหน้าที่พัสดุ `นางสาวนัทธมน คำประดิษฐ์`)
   - **`< 100,000` บาท**: กรอก 2 แถว (แถว 1 ผู้ตรวจรับ โดยเว้น Dropdown เป็น `-----เลือก-----` + แถว 2 เจ้าหน้าที่พัสดุ `นางสาวนัทธมน คำประดิษฐ์`)
   - ล้างคำว่า `undefined` ที่ค้างอยู่ในช่องว่างของตารางออกให้ทั้งหมดอัตโนมัติ

## วิธีติดตั้งลงในเบราว์เซอร์ Opera (ทำครั้งเดียว)

1. ดาวน์โหลดหรือคัดลอกโฟลเดอร์ **`bma-mis-autofill-extension`** ไปไว้ในคอมพิวเตอร์ของคุณ (ประกอบด้วยไฟล์ `manifest.json`, `background.js`, `content.js`, `panel.css`)
2. เปิดโปรแกรม **Opera**
3. ในช่อง URL ด้านบน พิมพ์ **`opera://extensions`** แล้วกด `Enter`
4. มองไปที่มุมขวาบนของหน้า Extensions แล้วกดเปิดสวิตช์ **`Developer mode`** (โหมดนักพัฒนา)
5. กดปุ่ม **`Load unpacked`** (โหลดส่วนขยายที่ยังไม่ได้แพ็ก) ที่มุมซ้ายบน
6. เลือกโฟลเดอร์ **`bma-mis-autofill-extension`** แล้วกด **Select Folder (เลือกโฟลเดอร์)**
7. เสร็จสิ้น! ส่วนขยาย **BMA MIS Auto-Filler** จะพร้อมทำงานทันที

# BMA MIS2 เบิกจ่ายอัตโนมัติ (`FRM_PAY_DOC : บันทึกใบขอเบิก`)

โปรแกรมหน้าต่างลอยบน Windows สำหรับช่วยกรอกข้อมูลลงหน้าต่าง **Oracle Forms (`ระบบการเงินจ่าย` / `FRM_PAY_DOC`)** ของระบบ MIS2 กทม. (`http://bmasso.bma.go.th/MIS2DirectLogins/index2.jsp`) โดยดึงฐานข้อมูลโดยตรงจาก **Google Sheets**

> **ทำไมจึงเป็นโปรแกรม Windows (.bat/.ps1) ไม่ใช่ส่วนขยาย Opera?**
> หน้าจัดซื้อ/เช่าเดิม (`PurHire`) เป็นหน้าเว็บ HTML ปกติจึงใช้ส่วนขยายเบราว์เซอร์ได้ แต่หน้า **ระบบการเงินจ่าย (`FRM_PAY_DOC`)** รันเป็นหน้าต่างโปรแกรม **Java Applet (Oracle Forms)** ซึ่งอยู่นอก DOM ของเบราว์เซอร์ โปรแกรมนี้จึงสร้างด้วย **Windows PowerShell + .NET WinForms + Win32 API** เพื่อทำงานร่วมกับ Oracle Forms ได้โดยตรง **ไม่ต้องติดตั้ง Python หรือโปรแกรมเสริมใดๆ** (ดับเบิลคลิกใช้งานได้ทันทีบน Windows 10/11)

## 🛡️ กติกาความปลอดภัย (Human-in-the-Loop)

1. **หยุดก่อนกดบันทึกทุกครั้ง** — โปรแกรม **ไม่มี** ฟังก์ชันกดปุ่มบันทึก (`Save` / `Ctrl+S` / `F10`) เจ้าหน้าที่จะเป็นคนตรวจสอบตัวเลข ภาษี ชื่อบัญชี และกดบันทึกเองทุกครั้ง
2. **ปุ่มหยุดฉุกเฉินทันที** — กด **`ESC`** บนคีย์บอร์ด หรือเลื่อนเมาส์ไปมุมซ้ายบนสุดของจอ โปรแกรมจะหยุดการกรอกทันที
3. **ป้องกันการเบิกซ้ำ** — ตรวจสอบคอลัมน์ H (`เลขที่ใบขอเบิก.../70`) ในชีต `MISS70` อัตโนมัติ หากมีเลขอยู่แล้วจะแจ้งเตือนสีแดงทันที
4. **คำนวณภาษีมูลค่าเพิ่ม 7% และหักภาษีเงินได้ 1% อัตโนมัติ** — คำนวณจากจำนวนเงินโครงการ (ฐานก่อน VAT = ยอดรวม ÷ 1.07) พร้อม **ยกเว้นการหักภาษีเงินได้ 1% (`0.00`) อัตโนมัติ** สำหรับ 4 หน่วยงาน/บริษัท ได้แก่ **สภากาชาด, เอเบิ้ล, องค์การเภสัชกรรม, ยูนีซัน**
5. **วางภาษาไทยแม่น 100% แม้คีย์บอร์ดเป็นภาษาไทย** — ใช้ Unicode Clipboard + Hardware Win32 `Ctrl+V` ไม่เพี้ยนภาษาไทย

## 🚀 วิธีติดตั้งและเริ่มใช้งาน (ไม่ต้องลงโปรแกรมเพิ่ม)

1. คัดลอกโฟลเดอร์ **`bma-mis2-pay-autofill`** ไปไว้ในเครื่องคอมพิวเตอร์ที่ใช้งาน MIS2
2. ดับเบิลคลิกไฟล์ **`START_MIS2_PAY_AUTOFILL.bat`** โปรแกรมจะเปิดเป็นหน้าต่างลอยอยู่ด้านขวาของจอ
3. กดปุ่ม **`🌐 เปิดเว็บ MIS2`** เพื่อเข้า `http://bmasso.bma.go.th/MIS2DirectLogins/index2.jsp` ➔ เลือก **ระบบการเงินจ่าย** ➔ เปิดหน้า **`FRM_PAY_DOC : บันทึกใบขอเบิก`**

### ตั้งพิกัดหน้าจอ 1 ครั้งต่อเครื่อง (ใช้เวลาไม่ถึง 1 นาที)
1. กดปุ่ม **`🎯 ตั้งพิกัด`** บนแถบด้านบนของโปรแกรม
2. เลือกรายการช่องในตาราง ➔ เลื่อนเมาส์ไปวางกลางช่องนั้นบนหน้าต่าง Oracle Forms ➔ กดปุ่ม **`F8`** เพื่อบันทึก (หากช่องไหนระบบ Oracle Forms ดึงมาให้เองแล้ว กด **`F9`** เพื่อข้ามได้)
3. พิกัดจะถูกบันทึกแบบ **สัมพัทธ์กับหน้าต่าง Oracle Forms** ลงในไฟล์ `calibration.json` (แม้จะเลื่อนย้ายหน้าต่าง Oracle Forms ไปตำแหน่งอื่นบนจอ ก็ยังคลิกตรงจุดเดิมเสมอ)

> **💡 ใช้ได้ทันทีแม้ยังไม่ตั้งพิกัด:** ข้างๆ ข้อมูลทุกช่องมีปุ่ม **`📋`** — แค่คลิกเคอร์เซอร์ในช่องของ Oracle Forms แล้วกดปุ่ม `📋` โปรแกรมจะสลับหน้าต่างและวางข้อมูลลงช่องนั้นให้ทันที!

## 📋 ขั้นตอนการใช้งานประจำวัน

1. **ค้นหารายการ:** พิมพ์รหัส `ซ.` (เช่น `7งบ`) หรือค้นหาชื่อบริษัทจาก `ทะเบียนบริษัท`
2. **ขั้นที่ 1 (ใบตรวจรับ):** กด **`⚡ ขั้นที่ 1: กรอกเลขใบตรวจรับ + กดแว่นขยาย 🔍`** ➔ เลือกรายการงบใน Popup (หรือกด **`⚡ ขั้นที่ 1.5`**) ➔ ตรวจสอบยอดเงินและภาษีในแท็บ `ข้อมูลฎีกาเบิกเงิน`
3. **ขั้นที่ 2 (แท็บผู้รับเงิน):** ติ๊กเลือกเฉพาะช่องที่ต้องการให้กรอก (โปรแกรมจำค่าที่ติ๊กไว้ให้) แล้วกด **`⚡ ขั้นที่ 2: กรอกแท็บ 'ผู้รับเงิน'`** ➔ ตรวจสอบรหัสสาขา (มีป้ายแสดงชื่อธนาคารและสาขาจากคอลัมน์ B, C ให้เทียบชัดเจน)
4. **ขั้นที่ 3 (แท็บรายละเอียดเงินเบิกจ่าย):** ตรวจสอบชื่อผู้เบิก, วันที่เบิก, จำนวนเอกสาร, และคำอธิบายรายการเบิก ➔ กด **`⚡ ขั้นที่ 3: กรอกแท็บ 'รายละเอียดเงินเบิกจ่าย'`**
5. **คนตรวจสอบและกดบันทึกเอง:** ตรวจสอบข้อมูลทั้งหมดในระบบ MIS2 แล้ว **กดปุ่มบันทึก (💾 / F10) ด้วยตนเองทุกครั้ง**
6. **บันทึกเลขที่ใบขอเบิกกลับลง `MISS70`:** นำเลขที่ใบขอเบิกที่ได้จากระบบ พิมพ์ใส่ช่องด้านล่างแล้วกด **`💾 บันทึกลง MISS70`** เพื่อเก็บประวัติลงคอลัมน์ H (ป้องกันการเบิกซ้ำ)

## 🔄 การอัปเดต Google Apps Script (เพื่อให้ซิงก์ `ทะเบียนบริษัท` และบันทึกคอลัมน์ H แบบ Live)

โค้ด Google Apps Script เวอร์ชันล่าสุดอยู่ในไฟล์ `../bma-mis-autofill-extension/google-apps-script.gs` (ใช้ร่วมกับส่วนขยายจัดซื้อ/เช่าได้ในตัวเดียว):
1. เปิด Google Sheet `Auto Crat-EGP70` ➔ เมนู **ส่วนขยาย (Extensions)** ➔ **Apps Script**
2. นำโค้ดจาก `google-apps-script.gs` ไปวางแทนของเดิมแล้วกดบันทึก
3. กด **ทำให้ใช้งานได้ (Deploy)** ➔ **จัดการการทำให้ใช้งานได้ (Manage deployments)** ➔ กดรูปดินสอแก้ไข ➔ เลือก **เวอร์ชันใหม่ (New version)** ➔ กด **ทำให้ใช้งานได้ (Deploy)** (URL เดิมใช้งานได้ต่อทั้งสองระบบทันที!)

*(หมายเหตุ: แม้ยังไม่ได้อัปเดต Apps Script โปรแกรมก็ยังใช้งานได้ทันทีโดยดึงข้อมูล `ทะเบียนบริษัท` 121 บริษัทจากไฟล์แคช/CSV ที่แนบมาให้เรียบร้อยแล้ว)*
